# Roadmap

| CP | Entrega | Critério de aceite |
|---|---|---|
| CP00 | Solução, shell WinUI, Core/Discovery e testes | Restore, build e testes em Windows |
| CP01 | Inventário de adaptadores | Estado e diagnósticos sem alterar configurações |
| CP02 | Bluetooth Classic/BLE | Dispositivos visíveis e serviços GATT acessíveis |
| CP03 | Wi-Fi/LAN, mDNS, SSDP e Wi-Fi Direct | Descoberta autorizada e APIs suportadas |
| CP04 | Analisador unificado | Normalização de protocolos, serviços e capacidades |
| CP05 | Gerenciador de conexões | Pareamento e sessões com consentimento |
| CP06 | Transferência segura | Envio/recebimento, validação e progresso |
| CP07 | Controle remoto | Teclado/mouse virtual em sessão autenticada |
| CP08 | Release | Testes integrados, instalador e documentação |

Cada checkpoint termina com testes, documentação e commit.
