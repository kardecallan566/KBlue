# Segurança

1. Descobrir não significa ter autorização para conectar.
2. Pareamento, conexão, transferência e controle exigem ação explícita do usuário.
3. Não implementar acesso remoto silencioso, bypass de autenticação ou exploração.
4. Limitar descoberta LAN às redes que o usuário tem autorização para inspecionar.
5. Validar nomes, tamanho e destino de arquivos recebidos; bloquear path traversal.
6. Sessões de controle serão autenticadas, revogáveis e visíveis.
7. Não registrar credenciais, chaves ou conteúdo privado em logs.
8. RSSI, fabricante e capacidades são opcionais e dependem de hardware/driver.
